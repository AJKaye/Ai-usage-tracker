# Token Build Pipeline

> How `tokens/**` becomes `dist/**`. Uses **Style Dictionary** (the de-facto DTCG token transformer). Until the pipeline is wired in Phase 0, the `dist/` files are hand-authored reference outputs and are safe to consume directly.

## What the build does

```
tokens/primitive.tokens.json ─┐
tokens/semantic.tokens.json  ─┤   Style Dictionary   ┌─ dist/tokens.css   (CSS custom properties: :root + [data-theme] + @media dark)  ← PRIMARY
tokens/component.tokens.json ─┼─────────────────────►├─ dist/tokens.ts    (typed TokenRef consts + applyTheme())
tokens/chart-palette.json    ─┤                       ├─ dist/tokens.json  (flattened DTCG export; optional Tailwind preset)
tokens/themes/*.json         ─┘                       └─ (one [data-theme="<name>"] scope per theme file)
```

- **Light** = the `$value` of each semantic/component token → emitted to `:root`.
- **Dark** = the `$extensions.mode.dark` of each token → emitted to **both** `@media (prefers-color-scheme: dark) :root:where(:not([data-theme="light"]))` **and** `:root[data-theme="dark"]` (toggle wins over OS).
- **Themes** = each `tokens/themes/<name>.json` overrides `brand.ramp` / fonts / radius (/ optional chart palette) → emitted as `:root[data-theme="<name>"]`. A combined `<name>-dark` scope is generated by composing the theme's brand overrides with the dark semantic values.
- The mandatory `prefers-reduced-motion` block is appended verbatim.

## Suggested setup (Phase 0)

```
npm i -D style-dictionary
# style-dictionary.config.mjs: register a custom "mode" transform that reads
# $extensions.mode.dark, and formatters that emit the :root / [data-theme] /
# @media scopes above. Build script: "tokens:build": "node style-dictionary.config.mjs"
```

## CI gates (fail the build)

1. **Stale dist** — rebuild in CI and `git diff --exit-code dist/` must be clean (dist is generated, never hand-edited in production).
2. **Palette gate** — `node scripts/validate_palette.mjs` on the default template **and every theme's chart palette**, light + dark. Exit 1 fails CI.
3. **No raw values in components** — stylelint rule (`declaration-property-value-disallowed-list`) rejects raw hex/px in component styles; only `var(--token)` allowed.
4. **Contrast** — assert semantic text-on-surface pairs meet AA in both modes (reuse the validator's exported `contrast()` helper).

## Consuming in the React app (Phase 8)

- Import `dist/tokens.css` once at the app root.
- Use `dist/tokens.ts` (`TOKEN`, `CHART_CATEGORICAL`, `applyTheme`) for type-safe references and runtime theme switching.
- Tenant resolution sets `<html data-theme="<tenant>">` (or `applyTheme(tenant)`); dark is an independent axis via the OS query or an explicit `data-theme="dark"` / combined scope.
