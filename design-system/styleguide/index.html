How this page works

Nothing here uses a raw color or size — every rule references a design token from ../dist/tokens.css. Use the switches above: Base ↔ SS&C swaps the tenant theme (brand ramp, fonts, radii); Light ↔ Dark swaps the mode. The entire page recomposes with no markup change. That is exactly how a real feature inherits a design change.
